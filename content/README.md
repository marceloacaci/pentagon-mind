# content/ — Modelo de Conteúdo Futuro

Esta pasta é a evolução para **autoria escalável** de briefings e análises, sem refatorar as páginas existentes.

## Estrutura

- `briefings/` — briefings de inteligência (curto prazo, regionais).
- `analysis/` — análises aprofundadas (doutrina, tecnologia, geopolítica).

## Template (`_template.md`)

Copie `_template.md` para criar um novo conteúdo. Siga `docs/editorial-guidelines.md` e `docs/checklists.md`.

> **Nota:** o site atual consome conteúdo embutido no HTML e dados em `data/`. Esta pasta é para quando o volume de conteúdo exigir separação. A integração é opcional e mantém a natureza estática.
